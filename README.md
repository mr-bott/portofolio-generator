
# 🌟 Portfolio Generator

**Portfolio Generator** is an innovative tool to help developers, designers, and professionals build stunning portfolios effortlessly. With just a few commands, you can create a responsive, customizable, and professional portfolio to showcase your work.

---

- **Link**: https://portzen.vercel.app
- 
## 🚀 Features

- **Dynamic Portfolio Generation**: Build a professional portfolio with minimal effort.
- **Various Templates**: Choose templates that suit your style.
- **Database Integration**: Stores user data and portfolio details securely in **MongoDB**.
- **Google OAuth Login**: Easily sign in using your Google account for secure and fast authentication.
- **Responsive Design**: Works seamlessly across devices using **ReactJS**.
- **Fast and Scalable**: Powered by **Node.js** and **Express.js** for a smooth experience.
- **Easy Share**: Share your Portfolio link to your friends , with one click.

## 🛠️ Technologies Used

- **MongoDB**: For secure and flexible data storage.

## 📦 Running on your machine

Follow these steps to set up and run the project locally:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/your-username/portfolio-generator.git
   cd portfolio-generator
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Set Up Environment Variables**:
   - Create a `.env` file in the root directory.
   - Add the following:
     ```
     MONGO_URI=<your_mongodb_connection_string>
     PORT=5000
     GOOGLE_CLIENT_ID=<your_google_client_id>
     GOOGLE_CLIENT_SECRET=<your_google_client_secret>
     GOOGLE_CALLBACK_URL=http://localhost:5000/auth/google/callback
     ```

4. **Start the Server**:
   ```bash
   npm start
   ```

5. **Access the Application**:
   - Open your browser and navigate to: `http://localhost:5000`
